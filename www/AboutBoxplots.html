The "Boxplot" figure generates summary statistics (e.g. min, median, max, quartiles) for the parameter of interest at each site selected. The user can selected how they want the summary statistics grouped (year, month, site). The "Figure Data" tab shows a screen-reader-friendly version of the data used to create the "Boxplot" figure. The "Exceedances" tab shows the data associated with any values that exceed the threshold values for the parameter of interest.

  • Year: Displays a different boxplot for each year. All data for each year will be included in the boxplot.
  • Month: Displays a different boxplot for each month. Data from all years contribute to each month's boxplot.
  • Site: Displays a different boxplot for each site in the selected park. All data collected at each site contributes to each boxplot.

Water Quality Thresholds

Some water quality parameters have thresholds that indicate "good" water quality. Checking the "Thresholds" box will display this threshold as a line on the figure.

Downloads

You can download the figure in .png format by hovering the mouse over the figure and then clicking the download icon. You can view the figure in full screen by hovering the mouse over the figure and then clicking the full screen icon. For each table, you can download a .csv or .xlsx version of the data.
